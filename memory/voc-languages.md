# 언어별 예상 VOC와 해결 검증

확인일: 2026-09-30. [언어 지도](language-atlas.md)의 55개 언어·언어 계열마다 **대표적인 장애 유형 하나**를 연결한다. 이는 실제 접수 건의 통계나 해당 언어의 모든 오류 목록이 아니다. 원인은 로그·재현으로 확인해야 하며, 버전별 명령과 API는 언어 지도에 연결된 공식 문서를 확인한다.

## 시스템·저수준·하드웨어

| C++ | 컨테이너 수정 뒤 iterator 참조 오류 | 재할당·삭제로 iterator 무효화 | 컨테이너별 무효화 규칙에 맞게 접근을 재설계하고 sanitizer 테스트 |
| Rust | 값 이동 뒤 사용/빌림 충돌로 빌드 실패 | 소유권·가변 빌림 범위 | 복제 남용 전에 소유권 경계를 조정하고 `cargo test`·`clippy` 확인 |
| Go | 동시 요청에서 map panic·데이터 경합 | 보호 없는 공유 가변 상태 | lock/채널/소유 goroutine으로 직렬화하고 `go test -race` 실행 |
| Zig | 처리량 증가와 함께 메모리 증가 | allocator·해제 경로 불일치 | 할당 주체와 해제 시점을 짝지어 실패 경로 포함 누수 검사 |
| D | 안전 영역 밖 포인터 오류 | GC 객체와 수동 메모리·`@safe` 경계 | 해당 경계를 축소하고 수명·안전 속성·런타임 검사 확인 |
| Nim | 참조 값이 예상과 다르게 공유됨 | 값/참조 의미와 메모리 관리 모드 오해 | 별칭을 최소화하고 동일 타깃 빌드에서 변이 테스트 |
| Assembly (x86) | 함수 호출 직후 충돌 | ABI, 레지스터 보존, 스택 정렬 위반 | 타깃 호출 규약과 레지스터/스택을 대조하고 디스어셈블리 검증 |
| CUDA C++ | kernel 결과가 틀리거나 접근 오류 | host/device 메모리 혼동·동기화 누락 | 전송 방향·범위를 확인하고 작은 입력에서 CPU 결과와 비교 |
| WebAssembly | 모듈 로드 실패·예상 밖 메모리 접근 | import/export 타입, 선형 메모리 경계 | 호스트와 모듈 인터페이스를 고정하고 최소 모듈로 재현 |
| Ada | `Constraint_Error` | 범위·인덱스 제약 위반 | 입력 범위와 타입 제약을 맞추고 경계값 테스트 |
| Fortran | 수치 결과가 배열 크기에 따라 달라짐 | 배열 shape·인덱스·정밀도 | 경계 검사와 작은 기준 배열, 정밀도 비교 실행 |
| Pascal / Object Pascal | 다른 환경에서 unit을 찾지 못함 | 컴파일러 버전·unit 탐색 경로 | 빌드 경로와 의존 unit을 명시하고 깨끗한 환경에서 재빌드 |
| VHDL | 시뮬레이션에서 신호 값이 즉시 바뀌지 않음 | 신호 할당과 delta cycle 이해 차이 | 파형에서 시간/델타를 추적하고 합성 가능 경로를 따로 테스트 |

## 공통 접수·검증 틀

`언어/런타임·버전 → 최소 재현 입력 → 기대/실제 결과 → 오류 코드·스택 → 원인 후보와 반증 → 적용 조치 → 경계·회귀 테스트 → 운영 지표 → 마지막 검증일`.

한 증상에 여러 원인이 있을 수 있다. 표의 조치를 실행 전에 반드시 증거로 해당 원인을 확인한다. 사용자에게 받은 실제 VOC 기록은 별도 허용 범위가 없으므로 이 문서에 포함하지 않는다.

# 지식 위키 갱신 절차

이 문서의 기준일은 2026-09-30이다. [출처 목록](sources.json)의 URL은 재검증의 시작점이다. 스크립트와 일정이 존재해도 실제 원문 비교·문서 수정·재검증이 끝나기 전에는 `확인일`을 새 날짜로 바꾸지 않는다.

## 인터넷이 없는 환경

```powershell
node C:\PRJ\apps\info\memory\maintenance.mjs --audit
node C:\PRJ\apps\info\memory\sync-cncf.mjs --check
node C:\PRJ\apps\info\memory\check-voc-coverage.mjs
rg -n "찾는 개념|오류 이름|프레임워크" C:\PRJ\apps\info\memory
```

`--audit`는 로컬 Markdown 링크, 문서 구조, 확인일의 경과를 검사한다. 오프라인에서 공식 사이트의 현재 내용을 검증했다고 주장하지 않는다.

## 인터넷이 허용된 환경

```powershell
node C:\PRJ\apps\info\memory\maintenance.mjs --probe
node C:\PRJ\apps\info\memory\sync-cncf.mjs --refresh
```

`--probe`는 공개 공식 URL과 GitHub 저장소 메타데이터를 확인하고 `probe-report.json`에 접근 결과를 남긴다. HTTP 성공이나 GitHub의 업데이트 시각은 내용이 정확하다는 증거가 아니다. 실패·접근 거부·속도 제한은 그대로 보고하며 우회하지 않는다.

## 실제 내용 갱신

1. `--audit`에서 오래된 페이지와 깨진 링크를 확인한다. 새 질문이나 장애가 생겼다면 해당 주제를 우선한다.
2. 공식 문서의 **릴리스/버전별 페이지**와 해당 기능의 원문을 읽는다. 중요한 변경은 가능하면 릴리스 노트와 API 문서를 함께 확인한다.
3. GitHub 구현을 근거로 쓸 때는 저장소·기본 브랜치·커밋 SHA·파일 경로·라이선스를 기록한다. `main`의 현재 코드와 출시된 버전을 혼동하지 않는다.
4. 이전 설명과 새 설명을 비교한다. 사실이 달라졌다면 지원 버전/조건을 쓰고, 오래된 설명을 조용히 덮어쓰지 않는다.
5. 본문과 관련 표, 예제, 출처를 함께 수정한 뒤 해당 문서의 확인일을 바꾼다. `sources.json.checkedAt`은 목록 전체를 다시 점검했을 때만 바꾼다.
6. `--audit`를 다시 실행하고 새 링크를 실제로 열어 확인한다. 결과를 `changes.md`에 날짜·페이지·출처·변경 이유로 기록한다.
7. [범위 장부](coverage.md)의 색인 항목 가운데 아직 가이드가 없는 분야를 하나 고른다. 개념·실패 사례·검증 절차를 채운 뒤 깊이 표시를 갱신한다. 단순 링크 추가를 완료로 세지 않는다.
8. CNCF 원본 스냅샷을 갱신했다면 커밋·항목 수·프로젝트 성숙도 변화와 라이선스 표기를 확인하고 [CNCF 지도](cncf-deep-dive.md)의 수치를 업데이트한다. 원본 데이터 갱신을 개별 프로젝트 설명·VOC 해결 검증으로 간주하지 않는다.
9. [VOC 사례집](voc-public.md)은 실제 공개 이슈와 문서 기반 증상 유형을 구별한다. 확인된 원인, 임시 완화, 해결 검증의 상태를 섞지 않는다.
10. [언어별 VOC](voc-languages.md)와 [CNCF 분야별 VOC](voc-cncf.md)의 대표 사례 범위는 `check-voc-coverage.mjs`로 검사한다. 이 검사는 항목 누락만 찾는다. 가능한 모든 사고나 해결의 정확성을 증명하지 않는다.

## 갱신 우선순위

- 보안 공지, 지원 종료, API 제거, 호환성 변화: 즉시 확인한다.
- 새 언어/프레임워크 요청 또는 재현된 장애: 해당 문서를 추가·수정한다.
- 주요 공식 릴리스·GitHub 기본 브랜치 변화: 월간 점검에서 비교한다.
- 변동이 적은 알고리즘 정의: 링크와 설명을 정기 점검하되, 단순 날짜 경과만으로 내용을 다시 쓴 척하지 않는다.

## 새 주제 작성 틀

`문제 정의 → 적용 버전/환경 → 핵심 원리 → 최소 예제 → 실패·경계 사례 → 테스트 → 공식 원문 URL → 확인일`. 외부 페이지의 원문을 대량 복제하지 말고 자체 설명으로 작성한다.

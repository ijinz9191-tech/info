# 검토 위키 기반 학습 데이터

Verified: 2026-10-02

공식 문서를 읽고 종합한 진단 시나리오의 모델 중립 JSONL입니다. 실제 공개 장애 사례·운영 재현·모델 가중치 학습 결과가 아닙니다. train/eval은 원본 위키 문서 단위로 분리했습니다. 의미 중복과 버전 적용성의 최종 평가 및 대상 모델별 토큰화·학습 설정은 미완료입니다. 같은 시나리오가 다른 페이지나 원문 데이터에도 등장할 수 있어 전체 코퍼스와의 의미 누수 검사는 별도로 필요합니다.

갱신은 수동 작업이며 예약 실행을 구성하지 않습니다. 각 예제에 원문 URL, 위키 문서 SHA-256, 버전, 시나리오 유형을 기록합니다.

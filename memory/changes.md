# 변경 기록

## 2026-09-30

- 정기 점검에서 React 19.3의 `useDeferredValue` 수정(공개 이슈 #35821), Spring Boot 4.0.8/4.1.1의 Kafka 소비자 보안 프로토콜 수정(공개 이슈 #51365), Kubernetes v1.37의 cgroup v1 기동 경계를 새 사례 3건으로 추가. 앞의 두 건은 업스트림 수정 기록이며 로컬 재현은 하지 않았다. VOC는 373건, OpenViking 가져오기 원본은 3,385개 파일·공식 사례 URL 268개로 갱신했다. 네이티브 인덱스는 여전히 미연결이다.
- OpenViking 공식 L0/L1/L2 리소스 계층에 맞춰 사례 370건과 CNCF Landscape 2,425개 항목, 개념 가이드 18개를 3,380개 파일로 재구성. 파일별 SHA-256 manifest와 URL 접근 점검기를 추가. 네이티브 서버·벡터 인덱스는 미연결로 명시.
- 사례 공식 URL 265개를 점검하고 실제 404 경로를 현재 공식 문서 주소로 갱신. HTTP 응답과 기술 주장 검증을 분리했으며 Clojure 자동 요청 거부와 OCaml 일시 503은 그대로 기록.
- 언어 75건, CNCF 분야·프로젝트 93건, 프레임워크·런타임 120건의 **추가 VOC 288건** 작성. 기존 사례를 합치면 언어 130건·CNCF 120건·프레임워크 120건(총 370건)이다. 각 건에 증상·확인할 증거·원인 가설·조치·검증·공식 확인 입구를 기재하고, 지도 전 항목의 누락·영역별 최소 100건·사례 ID 중복을 검사하도록 확장.
- 사용자 정의에 맞춰 VOC를 실제 접수 기록에 한정하지 않고 가능한 장애·문의 유형으로 확장. 언어 지도 55개 항목과 CNCF 프로젝트 27개 세부 분야 각각에 증상·원인 후보·조치·검증을 추가하고 누락 검사 스크립트 통과.
- CNCF Landscape 공식 커밋 `97b2e16fdf4147166df9427299998a83991b0958`의 데이터와 검색 색인 저장: 전체 2,425개 생태계 항목 중 `project` 필드가 있는 255개를 별도 목록으로 분리. 재생성/무결성 검사 스크립트 추가.
- React·Spring Boot의 실행 경계, 주변 라이브러리, 공개 이슈 기반 진단 문서와 VOC 사례집 추가. 해결 완료가 검증되지 않은 사례는 별도로 표시.
- 공개 출처 자동 점검 119개 중 118개 접근; Clojure 사이트는 자동 요청에 403. TanStack Query HTML의 일시 500 뒤 공식 Markdown 원문 URL로 점검해 접근을 확인. GitHub 저장소 페이지 32개 접근, API 메타데이터는 호출 한도로 미확인. URL 응답은 내용 정확성 검증과 구별.
- 언어 확장 지도에 시스템·JVM·.NET·스크립트·함수형·데이터·특수 목적 언어의 핵심 모델과 공식 출처를 추가.
- 웹·모바일·데스크톱·데이터·ML·인프라 프레임워크의 실행 계약을 확장 지도에 추가.
- 모바일·데스크톱·게임·임베디드·GPU·ML·보안·운영을 포함한 분야 지도와 데이터/분산, 보안/도구 가이드를 추가.
- 범위 장부에 현재 설명 깊이와 다음 확장 과제를 표시하고, GitHub 코드 탐색 대상 20개를 추가.
- 로컬 구조 검사 통과. 공개 URL 점검은 문서 92개 중 91개에 접근했고 Clojure 문서는 자동 요청에 403을 반환했다. GitHub 저장소 페이지 32개는 접근 가능했으나 API 호출 한도로 최신 메타데이터는 확인하지 못했다. 연결 결과를 내용 검증으로 간주하지 않는다.
- 범용 개발 지식 위키 최초 작성: 언어, 프레임워크, 알고리즘, 이벤트, 장애, 시스템 기초, 유명 GitHub 코드 읽기.
- 각 문서에 공식 원문 링크와 확인일을 남김. 원본 소스 전체와 개인·회사 자료는 이 위키에 포함하지 않음.
- 언어별 오류와 디버깅 출발점 추가.
- Kubernetes·Kafka·React의 공개 설계 문서를 바탕으로 자체 의사코드와 코드 읽기 질문 추가.

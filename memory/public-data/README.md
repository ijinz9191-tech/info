# 공개 CNCF Landscape 자료 표기

원본: [cncf/landscape](https://github.com/cncf/landscape)의 `landscape.yml`. 수집 커밋과 SHA-256은 [색인](cncf-landscape-index.json)에 기록한다. `landscape.yml`과 그 데이터로 만든 목록은 CNCF Landscape의 CC BY 4.0 대체 라이선스에 따라 출처를 표시하여 보관한다. 로고와 Crunchbase의 별도 라이선스가 적용되는 가공 자료는 복제하지 않았다.

`cncf-landscape.yml`은 공식 원본의 고정 스냅샷이다. `cncf-landscape-index.json`과 `cncf-projects.md`는 이름·분야·소속 상태·공개 URL의 검색용 파생 목록이다. 이 파일은 생태계 항목의 **색인**이며 2,427개 제품의 기능·보안·호환성 전부를 검증한 설명서가 아니다. 최신 프로젝트 상태는 [CNCF 프로젝트 페이지](https://www.cncf.io/projects/)에서 확인한다. 공개 저장소의 실제 문서 수집 결과는 [원문 범위](../corpus-overview.md)에 있다.

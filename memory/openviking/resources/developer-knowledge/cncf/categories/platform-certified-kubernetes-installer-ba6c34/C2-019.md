# C2-019 · Platform / Certified Kubernetes - Installer

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

재설치 뒤 노드가 control plane에 합류하지 않음; 인증서·토큰·네트워크 확인

## 원인 가설, 조치와 검증

bootstrap 자격 증명 만료/주소 변경 → 신뢰 경로 갱신; 새 노드 합류와 워크로드 스케줄 검증

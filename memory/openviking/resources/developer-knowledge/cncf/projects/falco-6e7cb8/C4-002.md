# C4-002 · Falco

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

정상 기준 이벤트도 알림이 없음; 드라이버·규칙 로딩·출력 채널 확인

## 원인 가설, 조치와 검증

커널 수집 경로 또는 출력 설정 실패 → 수집 상태 복구; 안전한 테스트 이벤트가 알림으로 도달하는지 검증

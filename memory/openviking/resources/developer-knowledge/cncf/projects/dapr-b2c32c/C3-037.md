# C3-037 · Dapr

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

pub/sub 요청은 성공하지만 구독자에 도달하지 않음; component scope·topic·sidecar 로그 확인

## 원인 가설, 조치와 검증

컴포넌트 범위 또는 구독 경로 불일치 → scope/route 수정; 고유 이벤트 ID로 end-to-end 추적

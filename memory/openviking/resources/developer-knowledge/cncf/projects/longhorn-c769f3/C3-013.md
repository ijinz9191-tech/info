# C3-013 · Longhorn

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

볼륨 재구성 중 Pod가 계속 대기; replica·disk·node 상태 확인

## 원인 가설, 조치와 검증

충분한 replica 배치 공간 부족 → 스토리지 배치·용량 회복; attach와 재구성 완료 확인

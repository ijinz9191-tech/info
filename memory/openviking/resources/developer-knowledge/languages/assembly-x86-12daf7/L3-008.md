# L3-008 · Assembly (x86)

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

함수 호출 뒤 레지스터 값이 바뀜; ABI의 caller/callee-saved 규칙 확인

## 원인 가설, 조치와 검증

보존 계약에 맞게 저장·복원; 다른 최적화 옵션으로 호출 시험

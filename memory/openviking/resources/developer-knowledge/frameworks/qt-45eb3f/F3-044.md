# F3-044 · Qt

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

`deleteLater` 호출 뒤 자원이 바로 해제되지 않음; event loop 실행 상태 확인

## 원인 가설, 조치와 검증

소유권·이벤트 루프 종료 순서 수정; 종료 시 누수 검사

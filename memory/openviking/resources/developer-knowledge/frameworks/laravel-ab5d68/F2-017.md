# F2-017 · Laravel

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

작업이 성공 응답을 내지만 큐 작업이 처리되지 않는다. queue connection, failed jobs, worker 상태를 본다.

## 원인 가설, 조치와 검증

작업이 잘못된 연결에 쌓였거나 worker가 실행되지 않는지 확인한다 → 연결 설정과 worker 운영을 맞춘다. 고유 작업 ID로 enqueue부터 완료까지 추적한다.

# F2-005 · Next.js

이 항목은 가능한 장애 시나리오다. 실제 접수나 해결 완료를 의미하지 않는다.

## 증상과 증거

수정한 서버 데이터가 화면에 늦게 반영된다. 해당 경로의 캐시 설정과 재검증 동작을 기록한다.

## 원인 가설, 조치와 검증

데이터 취득과 경로 캐시 정책이 기대와 다른지 확인한다 → 필요한 경로에서 명시적 재검증 또는 동적 취득을 적용한다. 수정 직후 응답과 이후 캐시 동작을 시험한다.

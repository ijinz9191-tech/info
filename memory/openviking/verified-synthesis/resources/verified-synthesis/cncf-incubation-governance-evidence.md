## 심사 자료를 해석하는 방법

이 문서는 운영 장애 사례가 아니라 공개 프로젝트의 관리·심사 근거다. 기존 graduation_criteria 문서는 현재 신청 템플릿으로 이동을 안내한다. 이전 기준만으로 현재 적합성을 판단하지 않는다.

- 신청 상태와 도입 조직의 근거를 구분한다. 템플릿의 빈 체크박스를 충족 증거로 세지 않는다.
- 기술 검토와 거버넌스 검토의 최신 문서·검토일을 확인한다.
- 의사결정, 유지관리자 합류·퇴임·역할 변경 절차가 문서와 실제 활동에 일치하는지 확인한다.
- 유지관리자 소속 변경 정책과 문서상 코드·문서 소유권을 검토한다.
- 공개 참여 방법·소통 채널·기여 경로의 실제 접근성을 확인한다.
- 아키텍처·사용 사례·로드맵·릴리스 절차의 근거를 연결한다.

## 적용 한계

신청 템플릿 일부를 읽어 종합했다. 프로젝트 승인 여부, 전체 심사 요건 충족, CNCF 전체 정책의 완전한 학습을 증명하지 않는다. 최신 템플릿과 실제 심사 기록을 다시 확인한다.
